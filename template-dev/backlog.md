# Backlog

Single ranked list of all features. Ranking follows §21.7 (tiers `first`, `then`, `later`) and the
priorities of §15.1; inside a tier, every feature is ranked after all of its dependencies.
The [roadmap](roadmap.md) groups the same features by phase; phase and rank can differ on purpose
(for example, minimal CI from phase 2 is needed early).

How to pick work: see the [agent implementation guide](agent-implementation-guide.md#picking-work).
`Depends on` lists feature numbers without the `FEAT-` prefix. `Agent-ready` is the value of
`agent_ready` in the feature file; a feature is only startable when all dependencies are
`implemented` as well.

This file and `epics/` are generated by [tools/generate_backlog.py](tools/README.md); do not edit
them by hand. When a feature changes, edit its frontmatter, run the generator and the verifier, and
commit everything in the same pull request. After the migration to GitHub Issues (`FEAT-048`), the
issue is authoritative.
