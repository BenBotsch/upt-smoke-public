# Planning

This directory holds long-lived planning documents: the roadmap, milestone goals and release
planning.

## What Belongs Here

- A roadmap that describes goals and their intended order, for example `roadmap.md`.
- Milestone or release plans that explain scope and rationale.

## What Does Not Belong Here

- Individual work items, task lists or their status. They live in GitHub Issues and milestones
  (see [ADR-0001](../architecture/adr/0001-use-github-issues.md)).
- Feature behavior. It lives in [feature specifications](../features/README.md).

Planning documents reference issues and milestones by number or link instead of copying them. Add
each new planning document to [docs/INDEX.md](../INDEX.md).
